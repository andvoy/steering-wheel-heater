# Подогрев руля

Русский · [English](README.en.md)

[Скачать комплект 1.9](downloads/steering-wheel-heater-1.9.zip)

Контроллер подогрева руля на Arduino Nano V3. Версия прошивки — **1.9**.

Одна кнопка включает и выключает нагрев. Контроллер плавно меняет мощность, поддерживает температуру и проверяет датчик и силовые ключи. Последнее состояние ON/OFF сохраняется между поездками.

## Текущая конфигурация

| Параметр | Значение |
|---|---|
| Контроллер | Arduino Nano V3, ATmega328P, 16 МГц |
| Питание нагревателя | 42 В |
| Обмотка | Вольфрам Ø0,204 мм, 19,47 Ом при 21 °C |
| Датчик | Vishay NTCLE100E3103JB0, 10 кОм, B = 3977 K |
| Силовые ключи | Два IRL540N последовательно по минусу нагревателя |
| Цель поддержания | 32 °C |
| Аварийная температура | 40 °C |

Температура относится к месту установки NTC. Равномерность нагрева поверхности зависит от намотки, положения датчика и покрытия руля.

## Подключение

Силовая цепь: **+42 В → нагреватель → Drain Q1 → Source Q1 → Drain Q2 → Source Q2 → GND**.

| Вывод Nano | Подключение |
|---|---|
| D9 | Gate Q1 через R2 220 Ом; R3 10 кОм между Gate и GND |
| D8 | Gate Q2 через R4 220 Ом; R5 10 кОм между Gate и GND |
| A0 | NTC на GND; R1 10 кОм на 5V; C1 100 нФ на GND |
| A1 | Drain Q1 через R6 220 кОм; R7 10 кОм и C2 10 нФ на GND |
| D2 | Кнопка на GND, встроенная подтяжка INPUT_PULLUP |
| D5 / D6 | Зелёный / красный светодиод через отдельные токоограничивающие резисторы |
| D13 | Встроенный светодиод L |

Для двухцветного светодиода используется общий катод на GND. Ток каждого цвета задаётся его последовательным резистором.

**C1: 104 — 100 нФ. C2: 103 — 10 нФ.** Оба конденсатора неполярные.

Питание Nano: внешний преобразователь 42→10 В, выход +10 В на VIN через J1.1, минус на GND через J1.2. Контакт 5V Nano питает измерительную цепь NTC; внешнее питание к нему в этой сборке не подключается. Силовая и управляющая части имеют общую землю с отдельным возвратным проводом силового тока.

[Принципиальная схема и монтажная плата](docs/steering-wheel-heater-1.9-wiring.pdf). J1: со стороны деталей слева GND, справа +10 В. Оранжевый провод от J1 идёт на VIN; отдельная перемычка от 5V Nano питает R1.

### Питание и конденсаторы

- C1: 100 нФ (104), C2: 10 нФ (103), оба неполярные. Установка 100 нФ вместо C2 замедляет установление A1 и может вызвать ложную ошибку самотеста с блокировкой нагрева.
- При питании от внешнего преобразователя 5 В в собранном прототипе наблюдались перезапуски при ШИМ. После перехода на 10 В через VIN работа стала стабильной. В документации принята эта схема питания.
- Повышающий преобразователь на 42 В выбирается с запасом по длительной мощности и с охлаждением. Холодная нагрузка при полном включении: 42² / 19,47 ≈ 90,6 Вт; ток 42 / 19,47 ≈ 2,16 А. Номинал на корпусе следует сверять с условиями охлаждения и допустимым входным током.

Преобразователь, использованный автором: [ссылка на Ozon](https://ozon.ru/t/EIjlFE6). Характеристики конкретного товара уточняются по его документации.

Arduino Nano: [ссылка на Ozon](https://ozon.ru/t/zLZbkiN). Вольфрамовая проволока: [ссылка на Ozon](https://ozon.ru/t/hiCkYJc).

## Работа

- Короткое нажатие переключает ON/OFF и сохраняет выбранное состояние.
- Включение запускает единый нагрев. До `NORMAL_FULL_POWER_C` задаётся максимальная мощность `MAX_PWM`; выше начинается регулирование PWM по температуре.
- PI-регулятор прогревает руль к 32 °C и поддерживает температуру. Переход определяется текущей температурой.
- Верхний предел PWM плавно снижается от 100% при 0 °C до примерно 39% при 30 °C. Регулятор выбирает мощность в пределах этой характеристики.
- При включении PWM нарастает плавно. Уменьшение мощности и аварийное отключение выполняются сразу.
- На экране отображается «НАГРЕВ», а около цели — «ПОДДЕРЖАНИЕ»: по умолчанию от 31 °C. Подпись отражает температуру; алгоритм управления остаётся общим.
- При 40 °C оба ключа закрываются, включается авария №2. Следующие силовые тесты разрешаются после остывания и успешного сброса.

Состояния ошибок хранятся в оперативной памяти. При аварии в EEPROM сохраняется OFF. Удержание кнопки 5 секунд запускает повторную проверку; успешный результат переводит модуль в OFF. Следующее короткое нажатие включает нагрев.

После перезапуска выполняются проверки датчика и силовой цепи, затем восстанавливается сохранённый ON/OFF. При ошибке №3 возврат силового питания отслеживается автоматически: устойчивый сигнал A1 в течение секунды запускает повторный тест. Успешное восстановление оставляет модуль в OFF.

## Индикация и монитор порта

В обычной работе зелёный светодиод обозначает OFF, красный — запрос ON. Встроенный L редко вспыхивает в OFF и светится постоянно при ON.

В аварии красный светодиод и L показывают номер ошибки: вспышка 300 мс, интервал 300 мс, пауза между сериями 2 секунды.

| Код | Причина |
|---|---|
| 2 | Перегрев |
| 3 | Питание нагревателя или обрыв его цепи |
| 4 | Датчик температуры |
| 5 | Проверка отключения Q1 |
| 6 | Проверка отключения Q2 |
| 7 | Проверка включения силовой цепи |

Монитор порта: **115200 бод**. Одна строка в секунду, затем пустая строка:

```text
Режим: НАГРЕВ | Температура: 29.3 °C | Нагрев: 39% | Питание: ~42.0 В | Мощность расч.: ~35.5 Вт | Ошибок нет
```

Напряжение оценивается через A1 в существующем тесте с выключенными ключами. Срок актуальности показания — 2 секунды. Мощность рассчитывается по формуле `U² / R × PWM / 255`, где R — сопротивление холодной обмотки. При прогреве сопротивление вольфрама растёт, поэтому фактическая мощность становится меньше расчётной. Процент на экране округляется до целого; расчёт мощности использует исходный PWM.

## Настройки и загрузка

Открыть [steering_wheel_heater_v1_9.ino](firmware/steering_wheel_heater_v1_9/steering_wheel_heater_v1_9.ino) в Arduino IDE. Выбрать Arduino Nano, подходящий для установленного загрузчика вариант ATmega328P и порт платы.

Комментарии у параметров описывают единицы и назначение. Основные настройки:

| Параметр | Назначение |
|---|---|
| `SUPPLY_V` | Напряжение обмотки и пороги силового теста |
| `HEATER_R_REF_OHM` | Холодное сопротивление для расчёта мощности |
| `TARGET_C` | Температура поддержания |
| `EMERGENCY_C` | Температура аварийного отключения |
| `NORMAL_FULL_POWER_C`, `NORMAL_GENTLE_C` | Температурный диапазон снижения предела PWM |
| `MAX_PWM`, `WARM_PWM` | Пределы PWM на холодном и тёплом руле |
| `HOLD_DISPLAY_BAND_C` | Зона индикации «ПОДДЕРЖАНИЕ» около цели |
| `PWM_RISE_PER_SECOND` | Плавность включения |
| `ADC_REF_V` | Измеренное напряжение между 5V и GND Nano |
| `DETAILED_DIAGNOSTICS` | Расширенный вывод показаний и результатов теста |

## Первый запуск

1. Проверить монтаж и полярность питания при отключённых источниках.
2. Проверить напряжение шины 5V, температуру по NTC и запуск режима OFF.
3. Подключить нагреватель и включить нагрев кнопкой. Наблюдать ток, температуру ключей и поверхности руля.
4. Проверить выключение кнопкой, повторное включение и сохранение ON/OFF после перезапуска.
5. Проверить равномерность нагрева, крепление проводов и электрическую изоляцию перед установкой.

## Проверки прошивки

Тесты выполняют скомпилированную прошивку в модели ATmega328P на AVR8js. Проверяются управление PWM, память ON/OFF, кнопка, перегрев, датчик, силовые ключи и телеметрия. Модель использует идеальные ключи и установившиеся значения АЦП; питание, переходные процессы и тепло проверяются на собранном модуле.

Сборка:

```sh
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328 --warnings all --build-path build firmware/steering_wheel_heater_v1_9
```

Для запуска тестов установить Node.js и зависимости `npm install`, указать `AVR_BIN` — каталог с `avr-nm` из инструментария Arduino AVR, затем выполнить:

```sh
npm test -- build
```

Результаты поставляемой сборки: [отчёт](verification/test-report.json), [параметры сборки](verification/build.txt).
